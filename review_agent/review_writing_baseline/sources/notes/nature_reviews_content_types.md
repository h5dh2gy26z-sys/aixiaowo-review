# Nature Reviews content types — Notes

Source: https://www.nature.com/nrct/content  
Local policy: summary only

## Why it matters

Even if you are not submitting to Nature Reviews, their **content-type distinctions** are useful as “writing modes” for an agent:

- Review: broad synthesis + authoritative framing
- Technical Review: method/tool/software comparison and practical guidance
- Roadmap: community-oriented state + milestones and future directions

## Baseline implications

- “Survey/Tutorial” in CS often maps to **Technical Review + Roadmap** combined: taxonomy + comparison tables + open problems.
- A useful agent should be able to “switch modes” while keeping the same corpus:
  - Mode A: taxonomy-first synthesis
  - Mode B: comparison-first engineering guide
  - Mode C: roadmap/future directions
