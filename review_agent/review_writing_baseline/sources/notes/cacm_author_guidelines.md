# CACM author guidelines — Notes

Source: https://cacm.acm.org/author-guidelines/  
Local policy: summary only

## Why it’s useful

- CACM optimizes for **broad readability**: explain concepts, minimize jargon, define terms, and write for a wider CS audience.

## Baseline implication

- Add a “reader model” requirement: each chapter begins with a short “what you’ll learn / why it matters” paragraph.
