# Nature Reviews: How to write a good review article (2024) — Notes

Source: https://www.nature.com/articles/s44222-024-00256-4  
Local policy: summary only (no full-text copying)

## Key takeaways (distilled)

- A strong review is not a “paper list”; it must **synthesize**, explain relationships, and make **claims** supported by the cited literature.
- Scope control matters: define a clear audience + boundaries early; avoid an unbounded “everything in the field” survey.
- Use **figures/tables/boxes** to compress complexity: taxonomy diagrams, method comparison tables, timeline/trend plots, and “key concepts” boxes.
- Build a narrative arc: problem framing → taxonomy/organization → comparisons/lessons → open problems/future directions.

## Candidate rules to extract into the project baseline

- R-SURVEY-CLAIMS: Every major conclusion sentence must be backed by at least one citation pointer (DOI/id in the project corpus).
- R-SURVEY-TAXONOMY: Provide an explicit taxonomy and place every included paper into it (even if “other/misc”).
- R-SURVEY-VISUALS: Each main section should have at least one visual compression artifact (table/figure/box).
