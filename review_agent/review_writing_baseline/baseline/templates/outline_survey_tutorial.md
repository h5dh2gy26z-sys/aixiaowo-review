# Survey/Tutorial Outline Template (baseline)

This template is meant to be filled after you have:

- `00_project.yaml` scope
- an initial `taxonomy.yaml`
- an abstract-screened included set

## Front matter

- Working title
- 150–250 word abstract: problem → organization/taxonomy → key insights → future directions
- Keywords (5–10)

## 1. Introduction

- What problem and why now?
- Who is the audience?
- What is in-scope / out-of-scope?
- Contribution list (taxonomy + comparison + lessons + open problems)

## 2. Background / Preliminaries (optional, but common)

- Definitions and notations
- Problem formulation(s)
- Evaluation settings and pitfalls

## 3. Taxonomy / Landscape

- Present the taxonomy and definitions.
- Map included works into the taxonomy (reference by `paper_id`/DOI).

## 4. Comparative Analysis

Required artifacts (at least one):

- method comparison table (stable schema)
- dataset/benchmark table
- “when to use what” decision table

## 5. Challenges / Limitations

- Failure modes, assumptions that break, reproducibility issues.

## 6. Open Problems & Future Directions

- Evidence-based gaps (not wishlists).
- Practical guidance: what to try next and why.

## 7. Conclusion

- What the field agrees on
- What remains unresolved
