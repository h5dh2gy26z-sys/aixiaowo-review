# Review Writing Baseline (Survey/Tutorial)

This folder is a local, **copyright-safe** baseline for building a computer-science style Survey/Tutorial paper:

- `sources/`: authoritative sources *as links + distilled notes* (avoid copying full publisher text)
- `baseline/`: measurable rubric + templates + table schemas
- `prompts/`: prompt building blocks (system + task prompts)
- `specs/`: artifact contracts, paths, and cross-platform conventions

If you later switch to an SLR-style workflow, add PRISMA-based artifacts under `baseline_slr/` instead of mixing rules into the Survey baseline.
